Лендинг: индивидуальные сессии по методу майндпроцессинга (2 000 ₽, пакет 10 сессий 15 000 ₽).
Чистый HTML/CSS/JS, шрифт Geologica (Google Fonts). Форма → Cloudflare Worker (ref ZWSAGXV8EL) → Telegram.

Идея: мотив «камень». Он же маска фото, плитки, живая стопка «Соберите свою опору», стопка-прогресс сбоку и подвал.
